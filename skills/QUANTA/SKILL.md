## Core workflow
1. **Evidence-first discovery:** Inspect supplied brief, repository, deployed routes, components, APIs, database schema, authentication, tests, workers, dependencies, and user journeys using authorized access. Label verified facts vs assumptions and inaccessible areas.
2. **Competitive intelligence:** Research relevant open-source and commercial competitors, compare feature availability, license, value, complexity, privacy, performance, costs, and priority. Do not claim complete market coverage without evidence or copy proprietary code.
3. **Master feature specification:** Organize must-have, competitive parity, differentiators, frontier research, user stories, acceptance criteria, APIs, database migrations, admin, analytics, SEO, i18n, accessibility, and privacy.
4. **Architecture:** Prefer preserving existing stacks; for greenfield, consider Next.js App Router, React, strict TypeScript, Prisma/PostgreSQL where appropriate. Optimize caching, indexing, deterministic computation, local algorithms, batch processing, and durable jobs. Do not require paid Abacus or LLM inference for normal deployed functionality; distinguish build-time agent, hosting, storage, bandwidth, and asset-generation expenses.
5. **Visual art direction:** Design an inspiring, futuristic, optimistic year-3629 experience: luminous cosmic imagery, breathtaking terrestrial scenery, holographic glass, layered depth, subtle volumetric lighting, typography, responsive layouts, and coherent design tokens. Generate original or properly licensed high-resolution imagery when authorized; export optimized WebP at quality 85, responsive variants and optional AVIF. Respect accessibility, legibility, contrast, and performance.
6. **Parallax/voxel engine:** Separate stars, nebula, sky, horizon, midground, foreground, atmospheric particles, and lighting into independently animated layers. Gyroscopic DeviceOrientation requires supported browser/device and user permission; fall back to pointer, touch, and scroll. Crossfade backgrounds with composited alpha, gradient masks, and opacity interpolation. 2D RGBA WebP is not a voxel volume: use actual 3D geometry/volumetric representation and GPU shaders where voxel rendering is required. Honor reduced motion, mobile GPU, battery, and low-end-device budgets.
7. **Comprehensive QA:** Validate every critical route, workflow, control, link, API contract, RBAC, authentication, form validation, migration/rollback, concurrency, error recovery, privacy, logging, backups, security headers, OWASP, WCAG 2.2 AA, keyboard/screen reader, SEO/schema, Core Web Vitals, responsive devices, cross-browser behavior, screenshots and visual regression. Detect clipping, overlapping content, poor contrast, ugly/inconsistent aesthetics, excessive motion, and broken images. Execute tests rather than inventing passes.
8. **Remediation:** Prioritize by severity, impact, frequency, risk, and effort. Fix root causes and shared layouts first, rerun affected and regression tests.
9. **Credit efficiency:** Inspect before generating, deduplicate, cache, batch work, run deterministic static and server-side tests before costly reasoning, and report costs and unknowns. Zero-credit runtime means no Abacus/paid LLM inference calls in core deployed workflows.
10. **Evidence gate:** Report executed commands, tested routes, actual pass/fail/blocked results, screenshots when available, changed files, unresolved issues, deployment URL if observed, and rollback plan. Never claim unobserved success.
