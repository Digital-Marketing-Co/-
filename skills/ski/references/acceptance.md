# Acceptance gates
Record each gate as verified/pass, failed, unresolved or not applicable, with evidence and corrective action. Do not treat an unperformed gate as passed.
- Source authenticity, exact authors/title/year/venue, observed stable/PDF URLs, access level and locators; no fabricated citations/results/pages.
- Actual search coverage and stopping rationale; unresolved/inaccessible list; no false saturation or systematic-review label.
- All communication domains; contextual alternatives; explicit language/intentionality limits; observation versus interpretation.
- Claim-to-source matrix and one source registry generating notes/bibliography; sequential note numbers; verified PDF locators where used.
- Every curriculum competency and field; evidence/consensus traceability; adjustable criteria; individualization and referral safeguards.
- Unique native 16:9 banners per substantive heading and separate inline cadence; real RGBA/logarithmic fade; anatomically/contextually approved; final compositing.
- Readable embedded fonts, wrapped tables, hyperlinks, pagination, intact glyphs, no overlap/clipping/blank pages; true typeset math where present; every rendered page visually inspected.
- All scripts actually executed on a representative run; manifest hashes; update/render reuse invalidation; forward-test realistic case; skill frontmatter validation.
- Saved skill commit/push and persistent user deliverables. A complete research run requires every applicable gate passed. Preserve partial artifacts but explicitly label them incomplete.
