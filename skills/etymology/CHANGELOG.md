# Changelog

## 3.0.0 — 2026-11-20
- Integrated /Perfect and /Final evidence-first iterative release gates.
- Added definitions-first sense inventory, constituent-by-constituent ancestry, separate phrase history, typed evidence graphs, structured JSON contract, and source provenance.
- Added linguistic, citation, chronology, accessibility, and visual QA checks, with explicit blocked status rather than false completion.
- Expanded regression case specifications for homographs, compounds, reconstructions, missing targets, and uncertainty.

## 2.1.0 — 2026-11-20
- Required definitions and chronological word-by-word language evolution maps for phrases and compounds.

## 2.0.0 — 2026-10-19
- Strengthened source hierarchy and claim-level citation requirements.
- Added confidence rubric, attestation checks, phonological and comparative analysis.
- Added flexible flags, Unicode and visual QA, accessible Markdown and PDF delivery rules.
- Explicitly prohibit invented attestations and unverified deployment claims.
