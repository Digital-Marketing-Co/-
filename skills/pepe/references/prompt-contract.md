# Prompt contract

Write this expansion before coding. Save it as `PROMPT.md` in the artifact folder.

## Headings (required)

1. Job — one sentence. What the host app gains by installing the panel.
2. Remainder lock — user's nouns, unchanged.
3. Install surface — custom element name, attributes, JS API, uninstall.
4. Information architecture — regions inside the panel only.
5. Visual floor — promptform, frost, volumetric field, 3D planes, holographic rim. No neon-city metaphor unless the remainder named one.
6. Motion — at least three coordinated motions, plus reduced-motion fallback.
7. States — empty, ready, busy, error, reduced-motion.
8. Inclusive — keyboard, names, focus, contrast, hit targets.
9. Host safety — Shadow DOM, no document-wide style leak, no required network.
10. Acceptance — list the QA checklist ids that must pass.

## Prompt voice

Imperative. Name files, attributes, and functions. Do not leave "make it nice" as a requirement. Each visual claim maps to a CSS or JS mechanism.
