# Expand ladder

Three written passes after the raw lock. Do not collapse them into one chat paragraph.

## Pass-1 — summary (`summary.md`)

120–220 words. Neutral. Only raw-supported claims.

A good pass-1 for a medal citation names the awarding office, the recipient as printed, the medal class as printed, and the one-sentence duty described. It does not narrate a career.

## Pass-2 — first expansion (`expand-1.md`)

800–1,600 words. Structure

1. Object — what the source physically is
2. Diplomatic reading — the raw claims in complete sentences
3. Printed actors — offices and names that appear
4. Public context — only with keepers, each sentence tagged `context`
5. Open questions — clipped lines, undated award, unnamed technique

Every sentence carries `origin` in `claims.jsonl` as `raw` or `context`. A context sentence without a keeper is a defect. Delete it.

## Pass-3 — second expansion (`expand-2.md`)

3,000–6,000 words or saturation. This file is the folio and book seed.

Required body nodes (relabel to the source)

1. Introduction and research questions
2. The physical document
3. Diplomatic transcript and textual cruxes
4. One chapter per major raw claim
5. Institutional and technical context from keepers
6. Historiography
7. Synthesis
8. Close and open problems

Chicago `{{n}}` markers begin in this pass. Note numbers follow first appearance. Bibliography is first-appearance order, not alphabetical.

## ITQE

Any quantitative description the topic supports becomes a compiled display figure plus an Identifier-Term-Quantity-Explanation table. Examples that often appear in military citations

- medal class and device count (Gold Star in lieu of a second award)
- platform class counts in a named year
- signal path or navigation-error bounds when a keeper states them
- date spans of a named weapons system

Explain every variable the first time. Chat may use KaTeX. Files must show compiled glyphs.

## Filename and title

Slug from the recipient or document type plus a short token from the award. Example `woodall-navy-commendation-citation`. Folio public name `YYYY-woodall-navy-commendation-citation-wca-folio.pdf`.
