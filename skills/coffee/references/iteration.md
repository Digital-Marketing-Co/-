# Iteration ceiling

One run of this skill returns at most 24 new full-bleed pages. That is the return ceiling. Do not plan 8 or 12 when the user did not name a smaller count.

- No page count in the ask: this run adds 24 pages.
- A named count at or under 24: this run adds that many.
- A named count over 24: this run adds 24. Say how many remain for the next run.
- A later `/coffee` on the same subject, or the words more / again / append: add another 24 unique pages to the same coffee.json. Do not replace earlier pages. Rebuild the PDF from the full page list.

New pages must be new scenes. Change vantage, hour, weather, object, or scale. Reject a prompt already stored on the book.
