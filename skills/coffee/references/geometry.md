# Geometry

Locked page, unless the user names an override in the same turn:

- landscape: 12 in wide by 9 in tall. Source 3600 x 2700 px. PDF 864 x 648 pt.
- square: 11 x 11 in. Source 3300 x 3300.
- portrait: 9 x 12 in. Source 2700 x 3600.

Never mix sizes inside one book.

Every printed page is one still drawn past the trim by 1.5 pt and clipped to the media box. Media box equals the page. No crop inset. No printer marks. No footer band. No alpha ramp. No side gutter. No letterbox.

The builder cover-crops inside the PDF step. A generate that is not 4:3 is cropped to fill, never padded with paper.

Do not pass mask="auto" to the PDF image draw. That flag punches bright pixels out of the still.
