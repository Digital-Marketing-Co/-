# Output types in descending power

Power is leverage for marketing conversion or academic presentation, not token cost. Rank 1 is the strongest default when the user does not name a type and the subject can support it.

| Rank | Slug | Label | Why it sits here | Typical stack |
|---:|---|---|---|---|
| 1 | web-app | Custom web application | Interactive product. Highest utility, capture, and demo power. | code write, local HTML/JS/CSS or Next-shaped static app |
| 2 | video | Cinematic video prompt pack | Highest emotional and brand-recall power. Paste into Aether Cinema. | gnitekram.org studio, shot list |
| 3 | dashboard | Interactive data app | Live argument. Stronger than a static chart deck. | web-app subset |
| 4 | coffee | Landscape coffee-table album | Full-bleed stills, zero margins, object-level awe. | /coffee |
| 5 | book | Illustrated chaptered book | Narrative plus unique banners and plates. | /book /banner /images /copyright |
| 6 | folio | WCA Ivy academic report | Compact PhD working paper, notes, ITQE. | /folio /itqe /latex /copyright |
| 7 | deep | Exhaustive Georgia monograph | Long-form authority document. | /deep /banner /iterate |
| 8 | deck | Presentation deck | Timed oral argument. | pptx skill |
| 9 | global | Country-by-country intel | Comparative authority with flags and banners. | /global |
| 10 | atlas | Figure-and-gazetteer atlas | Spatial inventory. | /atlas |
| 11 | list | Deduplicated instance catalog | Completeness claim. | /list /banner /images |
| 12 | site | Mirrored or original site | Distribution surface. | /copysite or new static site |
| 13 | still | Hero still / campaign image | Single-frame awe. | generate_image, /images |
| 14 | banner | 16-9 section banner | Document architecture, not a standalone campaign. | /banner |
| 15 | vector | Sharp SVG identity mark | Scale-invariant mark, not a scene. | /vector /upscale |
| 16 | audio | Voice, bed, or ringtone | Time-based but lower visual authority. | Voice, /ringtone |
| 17 | sheet | Quantitative workbook | Proof, not persuasion. | xlsx skill |
| 18 | letter | Formal letter or proposal | Direct ask. | docx skill |
| 19 | copy | Short marketing or academic copy | Necessary but lowest standalone power. | chat |

When two types fit, pick the higher rank unless the user named the lower one.

Video is rank 2 because this environment writes the prompt pack; the studio at https://gnitekram.org/ renders motion. Do not pretend an MP4 landed in artifacts unless a tool actually wrote one.
