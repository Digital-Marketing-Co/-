# /appideas

Accept a business idea, prompt or document. Identify user personas, workflows, existing commercial and open-source applications, feature inventory, differentiation opportunities, licensing and security risks, feasibility, operating costs and proposed monetization. Provide source URLs and access dates for every externally derived claim; distinguish observations from estimates. Deduplicate ideas and rank using explicit weighted criteria. Output a structured application specification including functional and nonfunctional requirements, data model, API contracts, UX, accessibility, QA plan, deployment dependencies, and machine-readable JSON. Never invent citations or guarantee novelty, demand, licensing rights, or build time. Invoke /deep, /iterate, /pe, /qa and /visual_QA when available; otherwise identify unavailable workflows. Never claim production deployment without direct evidence.
