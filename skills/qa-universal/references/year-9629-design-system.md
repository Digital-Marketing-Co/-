# Year 9629 Universal Publication Design Standard

This is a creative art-direction specification, not a prediction about future technology. Prioritize scientific accuracy, readability, accessibility and context-specific imagery over decorative spectacle.

## Design language
Use sophisticated editorial hierarchy, generous whitespace, refined typography, deep navy, luminous cyan, warm gold and clean porcelain tones as context allows. Use realistic volumetric lighting and restrained holographic depth in illustrations. Long-form body pages should remain highly readable, usually with light backgrounds and dark text. Never encode critical meaning in color alone.

## Format matrix
- PDF: vector text and mathematical notation, embedded fonts, accessible structure where supported, verified hyperlinks, render every page, no clipped glyphs.
- DOCX: native heading styles, editable tables, meaningful image alternatives, correct page breaks, inspect rendered pages.
- PPTX: slide hierarchy, 16:9 by default, accessible reading order, presenter notes, no off-slide objects, inspect every slide.
- XLSX: native formulas, verifiable calculations, readable columns, labeled charts, print ranges, freeze panes, avoid hidden data.
- HTML: responsive semantic layout, keyboard navigation, visible focus, reduced-motion support, WCAG 2.2 AA target.
- SVG and PNG: correct aspect ratios, appropriate pixel dimensions, inspect at full size, no unintended alpha artifacts.
- RTF, TXT, Markdown, CSV, ODS, ODT and ODP: preserve native format, encoding and editability; do not promise unsupported visual effects.
- Institutional correspondence: restrained, authoritative design; do not fabricate official seals or endorsement.
- Scientific diagrams and maps: use verifiable data and exact labels, not image-generation guesses.

## Contextual AI imagery
For each figure, record section ID, factual subject, required objects, source evidence, intended role, alt text, caption, crop safe area and prohibited inventions. A /banner owns one unique section or subsection banner. /images owns supplemental figures, not duplicate banners. Commands can appear anywhere in the user's prompt; shared orchestration resolves dependencies once.

Generate multiple distinct candidates only when image generation is available and requested. Score candidates on factual/contextual fidelity (25%), readability/accessibility (25%), composition (20%), editorial hierarchy (15%), realism (10%) and performance (5%). Critical factual, security or accessibility defects override scores. Inspect object counts, perspective, shadows, anatomy, numbers, spelling, clipping, watermarks, resolution and duplicates. Never claim an upscale creates missing real detail. Label speculative scientific concept art as illustrative.

## Quality gates
1. Verify data, provenance, citations and mathematical claims.
2. Validate native document structure and equation-to-ITQE-table pairing.
3. Inspect generated artwork for semantic relevance and artifacts.
4. Render and inspect every page, slide, printable sheet or image.
5. Check accessibility, responsiveness and print fidelity.
6. Reopen exports and check size optimization.
7. Preserve before/after evidence, measured scores, and unresolved defects.

Unavailable renderers, image generators or inspections are BLOCKED, not PASS. Iterate at most three candidate rounds before reporting unresolved issues. No absolute error-free guarantee without evidence.
