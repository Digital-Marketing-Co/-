## Interactive selection
Present font-family choices as a clickable dropdown with each font label rendered in its own font where supported; provide a legible fallback. Paragraph body text size is the global relative typography baseline; scale headings, captions, footnotes, tables and document variants from that baseline with bounded accessibility minima.

Provide an accessible color studio with color tokens, perceptual contrast checks, print-safe alternatives and live preview. Present effect selections as futuristic holographic binary tiles with clear selected/unselected states, keyboard navigation, screen-reader labels, high contrast and reduced motion. Never rely solely on glow, color, gyroscope, hover or double tap. For numeric sliders, allow double-tap to edit the displayed value, plus an obvious accessible edit action.

## Canonical capability model
Each registry item must include: stable ID, canonical name, prior aliases, family, type, scientific mechanism, effect or algorithm parameters, renderer backend, required hardware, export support, accessible fallback, performance budget, provenance, implementation status, tests and deduplication decision.

Types are `visual_effect`, `rendering_technique`, `optical_hardware`, `interaction`, `scientific_visualization`, and `validation_capability`. Do not market an optical measurement or QA check as a visual effect.

Merge only semantically equivalent behaviors after checking optical mechanism, mathematical model, algorithm, input/output, parameters and supported platforms. Preserve every previous alias. Represent overlapping techniques as variants or related families when their implementations differ. Keep a reviewable decision ledger; never silently delete entries.

## Rendering truthfulness
CSS/SVG/Canvas/WebGL/WebGPU may emulate optical appearances on a screen. Actual electroholography, coherent wavefront reconstruction, photorefractive recording and volumetric display techniques require appropriate hardware. Label simulations accurately. Use accessible static alternatives for PDF, DOCX and unsupported PPTX features. Avoid flashing and vestibular hazards.
