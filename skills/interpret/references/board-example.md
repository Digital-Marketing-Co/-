# Board example

A house board may look like a left-to-right chain

ITQE label — a stacked velocity-or-volume mark with GLOBAL — a double arrow — a pictogram — a real-GDP time derivative — a much-greater-than threshold.

Inventory that chain as separate objects. Do not fuse the derivative and the threshold into one row. Do not name the pictogram as "growth" unless a legend or the data says so.

Suggested encounter ids for a board of that shape

- eq-001 annotation — catalog or method label (ITQE and any number beside it)
- eq-002 glyph or definition — the stacked V/M (or V_M) plus the GLOBAL caption
- eq-003 arrow — implication or sequencing
- eq-004 annotation — unlabeled pictogram
- eq-005 rate — partial of real GDP with respect to time
- eq-006 inequality — the threshold on the right-hand side

Relevance on a GDP-linked set usually puts eq-005 first, then eq-006, then eq-002 if velocity or money is in the data, then the arrow, then the pictogram, then the catalog label. Restate that order only after the scores are written. If the linked data is a money-velocity series and not a GDP series, eq-002 rises.

Rival readings to keep on the threshold glyph

- phi (golden ratio) when the stroke is a closed loop with a vertical
- empty set or slashed circle when the stroke is a cut oval
- zero when the loop is small and unsigned

Write all three into `alt_readings` when the photograph is ambiguous. Let the data and a source kill two of them. Do not pick the prettiest letter.
