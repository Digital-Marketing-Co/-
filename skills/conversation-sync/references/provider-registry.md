## Capability Tracking

For each product surface and authorized account, independently record:

- GitHub access type and evidence URL
- Vercel access type and evidence URL
- History access method, pagination support, timestamp precision, branch support, project instruction support, file byte recovery, revision check method
- ChatGPT destination verification methods
- Verification date, account/plan restrictions, test results

Discovery alone does not authorize access or install a connector.
