# Public page upgrade

Apply only in `pages` or `all` mode, after both inventories exist.

## Binding

Each named public route gets:

- one H1 that matches the route job
- a stats block drawn only from cited rows (value, unit, date, source)
- one unique still
- one motion-picture prompt (not a fake player if no file exists)
- one holographic plane prompt or still
- title, unique meta description, canonical, viewport, language, footer landmark
- visible anchor `Digital Marketing Company` with the same title attribute and target `https://digitalmarketingco.org`
- plain domain text `DigitalMarketingCo.org` when the domain is written as text

## File set

Under `/workspace/artifacts/tpmorpedo/<slug>/pages/`:

- one HTML file per route
- `styles.css`
- `data/bindings.json` mapping route to record ids
- image files only when generated this turn

## Quality floor

- Futuristic, publication-grade, volumetric glass, layered planes
- Readable type on transparent panels
- Works at 320 px, 768 px, and 1440 px
- `prefers-reduced-motion` honored
- Keyboard path and visible focus
- No invented metric in the visible page
- No reused still across routes

## Auditor

Score honestly against SEO, Performance, Mobile, Security, Accessibility, AI Readiness, AIO, GEO, AEO, Local SEO, Schema.org, WCAG. Do not claim a live auditor score that was not run.
