# Practical analytical matrix (monograph Ch. 13)

Run this checklist on the finished draft before sending.

1. Stimulus and medium — here, prose story. Optional dialogue, optional one-liner tags.
2. Primary mechanism — name it in Mechanism Notes, not in the story.
3. Resolution profile — immediate, delayed, partial, or intentionally unresolved. Pick one and stick to it for the main engine.
4. Appraisal — must stay benign or distant enough to stay comic.
5. Target — self, object, institution, convention, idea. Flag any person-target.
6. Function — entertainment first. Affiliation or coping second.
7. Performance layer — timing, deadpan narration, pause, repetition, bathos.
8. Power analysis — can every person in the scene decline the joke without penalty?
9. Knowledge requirements — planted in the setup, not assumed from a private chat.
10. Outcome — amusement. Groan-puns are allowed if labeled as such in the notes. Offense is a fail unless the user asked for Juvenalian satire of an institution.
