# Banner subject fidelity

Read the section's named objects, claims, and evidence before writing a prompt. Use a distinct context-specific composition for each required heading. Label generated reconstructions as conceptual and cite inspected sources for historical or scientific details. Do not add unsupported physical capabilities, architecture, species, labels, or quantitative values.

Use deterministic rendering for exact symbols and diagrams. Keep banners separate from equation plates and inline explanatory images. Record source dimensions, prompt, generation identity, rights status, checksum, caption, heading identity, and actual output placement. Follow the calling skill's opacity, aspect ratio, transparency, and no-shadow requirements.

Apply `visual-system/references/quality-design.md` for design and `images/references/uniqueness.md` when present for duplicate checks. Verify the actual rebuilt artifact rather than declaring success from image file creation alone.
