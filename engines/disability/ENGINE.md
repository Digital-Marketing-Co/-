# Disability Engine
Both `P` and `D` invoke this same engine. Apply accessibility-first assistance, resume the latest unfinished authorized task if no new task is supplied, minimize typing and taps, perform available safe actions, and iterate testing and repair until verified completion or a genuine blocker. Preserve user consent, privacy, security, and tool limitations.

Compatibility aliases: `/disability`, `/disabled`, `/p`, `/proceed`, `/d`. The former skill paths `skills/disabled/SKILL.md` and `skills/disability/SKILL.md` remain supported as forwarding compatibility entries. Do not claim this convention automatically changes third-party runtimes.
