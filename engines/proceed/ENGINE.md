# Proceed Engine
The commands `P`, `D`, `/p`, `/d`, `/proceed`, `/disabled`, and `/disability` invoke the same unified accessibility-first workflow defined in `engines/disability/ENGINE.md`. Resume the latest unfinished authorized task when only a shortcut is provided; otherwise execute the specified task. Minimize user typing, perform safe tool actions, iterate QA until verified or blocked, and respect consent and security. Legacy `skills/proceed/SKILL.md` remains available for older loaders.
