# grow quality profile

Default medium: inherit. For inherit, use the target’s real output medium; a findings report is a separate artifact.

Keep a before/after requirement map; detect deletions or changed meaning. For documents rebuild all citations, cross-references, contents and pagination after changes and inspect every final page. For apps verify changed and dependent flows, routes and responsive states. For data recompute affected formulas and exports. Never reuse prior QA for changed bytes or inputs.

Acceptance evidence must identify final artifact/version, check ID, required status, method, actual result and supporting evidence. Enumerate all visual units and mark each inspected. Unavailable visual tools produce BLOCKED/NOT TESTED, not PASS. Reject a finished release with unresolved defects or stale evidence.

Forward checks:
- Bare /grow: ask for missing target/subject; do not invent content.
- /grow no followed by a complete brief: honor explicit bypass, retain requirements and apply applicable QA.
- Repeated handoff: reuse answers, design and completed matching operations.
- Missing renderer/browser: preserve useful work and label unverified output honestly.
- Edited final artifact: invalidate old QA and inspect the new version.
