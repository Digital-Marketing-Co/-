# Locked reply order

Emit in this order. Do not add a preface that recites the monograph.

## 1. Title

One line. Wit allowed. No subtitle lecture.

## 2. Story

500–900 words unless the user asked for a shorter joke form.

- Open on a concrete base model the reader already believes.
- First violation by the end of the second short scene.
- Three-beat escalation or heightening.
- One callback to an early concrete detail.
- At least one tag after the biggest laugh.
- Close on a last small reversal or anticlimax, not a moral.

Do not write "the joke is that" or "this is funny because."

## 3. Mechanism Notes

Heading exactly `Mechanism Notes`.

Five to eight bullets. Each bullet is

- **Form name** as it appears in the monograph taxonomy (for example Incongruity-resolution, Paraprosdokian, Rule of three, Callback, Bathos, Bureaucratic humor, Deadpan)
- then an em dash
- then one clause naming the line or beat where it fired

Do not grade the story. Do not cite page numbers unless the user asked.

## 4. Optional variant line

One sentence, only if useful

Want a second pass in a different loadout — deadpan, farce, Horatian satire, or observational?

Skip this line when the user already named the loadout.
