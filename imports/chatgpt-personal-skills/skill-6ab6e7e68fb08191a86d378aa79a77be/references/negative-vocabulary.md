# Negative vocabulary

Load `assets/negative-keywords.csv` before any concatenated generate prompt for flags, banners, or charts.

Do not write these tokens into a generate prompt

- house routing words — atlas, folio, deep, exhaustive, gazette, plate
- vendor words — AI, xAI, ChatGPT
- slash flags as visible text on an image

Keep `/atlas`, `/folio`, `/deep`, `/global`, `/banner` as invocation flags only.

Country banners name a real place. Do not prompt a metaphor building, a glass globe, a corporate seal, or a collage of many flags.

Flags are cloth in motion. Do not prompt emoji, app icons, or incorrect historic banners.
