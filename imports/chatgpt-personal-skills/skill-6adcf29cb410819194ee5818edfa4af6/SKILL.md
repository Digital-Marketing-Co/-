# Doc

Read [the shared output contract](references/output-contract.md) before execution.

## Interactive start

Show the proposed output plan and reuse prior choices. Ask at most two useful questions only for missing material context: Purpose/audience and output format or document mode. Honor explicit no-questions/bypass settings. Use the shared 4629 style phase for a new designed output, once across handoffs.

## Execution

Create the requested document as a complete, usable artifact. Infer or honor the stated mode: textbook, monograph, white paper, technical/evidence report, business proposal, infographic or magazine. Preserve the brief and prior answers. Use adaptive intake only for material unknowns. Research factual claims using relevant authoritative sources; verify citations, supporting passages and locators. Build a coherent structure and substantial content appropriate to the audience. Preserve an already selected design; otherwise use the shared interactive 4629 style phase for a new designed output. Apply distinct contextual artwork and compiled mathematics where relevant. Rebuild citations and cross-references after changes. Render and inspect every final page, repair defects, and deliver the requested document and editable source where applicable, with honest validation results and remaining gaps.

## Specialist routing

Use textbook for teaching; book for narrative; PDF or documents authoring skill for actual files; presentations for slides. Preserve mode rather than routing every document to textbook.

## Required QA and visual QA

Verify substantive completeness, claim support, bibliography/citation reading order, definitions, calculation units and requested source files. Render every final page; inspect headings, paragraphs, tables, citations, artwork, equations, links, margins, footers, glyphs and page breaks. Preserve live searchable text. Follow the shared repair and release gates. Never mark unexecuted checks passed.

Read [the endpoint quality profile](references/quality-profile.md) for requirements and tests.
