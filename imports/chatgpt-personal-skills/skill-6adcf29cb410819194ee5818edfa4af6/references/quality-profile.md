# doc quality profile

Default medium: document. For inherit, use the target’s real output medium; a findings report is a separate artifact.

Verify substantive completeness, claim support, bibliography/citation reading order, definitions, calculation units and requested source files. Render every final page; inspect headings, paragraphs, tables, citations, artwork, equations, links, margins, footers, glyphs and page breaks. Preserve live searchable text.

Acceptance evidence must identify final artifact/version, check ID, required status, method, actual result and supporting evidence. Enumerate all visual units and mark each inspected. Unavailable visual tools produce BLOCKED/NOT TESTED, not PASS. Reject a finished release with unresolved defects or stale evidence.

Forward checks:
- Bare /doc: ask for missing target/subject; do not invent content.
- /doc no followed by a complete brief: honor explicit bypass, retain requirements and apply applicable QA.
- Repeated handoff: reuse answers, design and completed matching operations.
- Missing renderer/browser: preserve useful work and label unverified output honestly.
- Edited final artifact: invalidate old QA and inspect the new version.
