## Rebuild WCA Ivy citations after every revision

Apply the current `academy-ivy-biblio` workflow. Default to Chicago notes and bibliography with the WCA first-appearance ordering convention unless the user explicitly requires a different citation system.

- Traverse final reading order: main prose, equations, tables, captions, figure notes, appendices, and supplements. Use the actual reading order, not arbitrary storage order.
- Number citation NOTE EVENTS contiguously from 1 through N across the whole document; do not restart by chapter or page. Use full first notes and shortened later notes. A repeated work can produce several separately numbered notes.
- Keep a separate deduplicated WORK registry. Order the unique-work bibliography by each work's first citation, not alphabetically and not by the last edit time. Do not invent an independent bibliography number series in Chicago style or confuse work counts with note-event counts.
- If an explicitly selected numeric work-reference style is used, assign each work a number at first occurrence and reuse it thereafter. Do not impose Chicago event-number behavior on that style.
- Recompute every superscript, grouped marker, footnote, endnote, shortened note, bibliography entry, hyperlink, backlink, locator, and cross-reference after insertions, moves, or removals. Separate adjacent note numbers visibly according to the chosen style. Remove gaps, duplicate markers, dangling references, unused entries, and unresolved placeholders; preserve explicitly requested further reading in a separate labeled list.

Check authors, title, date/version, DOI or canonical identity, accessible source, claim support, and actual page/section locators. Distinguish source access limits from verification.
