# Visual production contract
Use a restrained futuristic navy/cyan/pearl system with generous readable body columns, embedded Unicode-capable fonts, 11–12 pt body text, clear headings and dark-on-light text. Keep complex images away from body text. Banners are native 16:9 compositions, unique for every substantive section and subsection, spanning both side trim edges and top trim on section-opening pages. Additional unique AI illustrations appear approximately every 500 substantive words; measure that cadence separately and report actual intervals. Never recycle a banner as an inline illustration.
Generate anatomically plausible dogs and behavior relevant to each section. Inspect paws, eyes, limbs, muzzle, tail and interactions. Label all generated behavior as conceptual representation, not empirical evidence. For precise diagrams/charts use vector drawing with real verified data or clearly marked conceptual quantities.
Preserve RGBA source assets. Apply alpha A(y)=1-log(1+9t)/log(10), t clamped to [0,1] over the transition; above transition A=1, bottom A=0. Use a restrained deterministic voxel modulation only within lower transition, preserving endpoints and avoiding sharp opacity reversals. Use scripts/alpha_transition.py only for the explicitly requested deterministic alpha transformation, not to create the underlying illustration. Multiply existing alpha rather than destroying it; do not simulate transparency with white or checkerboard. Verify endpoints, alpha-channel variation, source ratio, pixel/file/perceptual uniqueness and final PDF compositing with two contrasting backgrounds. Record image ID, hash, prompt, generation method/date, placement, purpose, dimensions, alpha range, visual approval and word position in image_inventory.json.
Render every PDF page. Inspect all pages at readable resolution; use contact sheets for overview only. Test table wrapping, notes, links, pagination, clipping/overlap, glyphs and blank artifacts. Typeset mathematics with genuine TeX/KaTeX or vector math engine, never unsupported Unicode approximations.
