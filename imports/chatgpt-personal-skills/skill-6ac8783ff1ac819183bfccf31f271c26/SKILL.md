# SKI: canine communication and training

## Inputs and modes
Parse `/ski [research|update|dog|render] [focus]`. Default to research. Accept supplied sources, prior output directory, cutoff date, languages, region, audience, and dog profile. In dog mode collect age, health, sensory/mobility status, household, observed behavior, antecedents, consequences, bite history, available equipment, preferred rewards, and practical constraints. Continue general research while material case details remain missing; never invent a dog profile.
Read references/output-templates.md when creating run records and writable plans. Read references/protocol.md before research; references/evidence-schema.json and references/quality-rubric.md before extraction; references/curriculum-contract.md before training; references/visual-contract.md before authoring; references/acceptance.md before delivery.

## Workflow
1. Run `python scripts/init_run.py RUN_DIR --mode research` (or the requested mode) to initialize empty records in a new directory; never treat initialized records as results. Create a run directory and manifest with invocation, search date, cutoff, language limits, versions, and artifact dependencies. Reuse only artifacts whose hashes and verification states remain current. Do not silently overwrite prior source records.
2. Preregister bounded questions and inclusion/exclusion rules using protocol.md. Search ethology, comparative cognition, behavior, veterinary medicine, neuroscience, sensory biology, learning theory, and human–animal interaction. Search Ivy League institutions and relevant institutions globally, judging methods rather than prestige. Prefer original authoritative PDFs; include authoritative HTML when needed.
3. Log every actual query, platform, date, result inspection, eligibility decision and retrieval failure. Follow references backward and citations forward; identify contradictions and missing populations; run targeted gap passes. Never invent counts, database access, citations or saturation. Describe this as a structured narrative synthesis unless formal systematic-review requirements are actually satisfied.
4. Extract each eligible source using the schema. Record authors, title, date, venue/institution, DOI/stable URL, observed PDF URL, access level, design, sample, methods, outcomes, limitations, relevance and verified locators. Leave unknown values null with an explanation. Abstract-only records may support only what the abstract establishes.
5. Create a claim-level evidence matrix. Separate observation, interpretation, empirical inference and recommendation. Distinguish robust evidence, provisional association, professional consensus, hypothesis and unsupported popular claims. Apply the rubric without collapsing bias into an unvalidated numerical score. Resolve disagreement by scope and design, not majority vote.
6. Cover posture, tension, movement, orientation, approach/retreat, freezing and weight; face/eyes/ears/mouth/gaze/blinking/sclera; tail/anatomy/breed/individual variability; all vocal classes and acoustic/context differences; scent/marking/glands; touch/proximity/play/affiliation/spacing/sequences; fear/anxiety/arousal/frustration/conflict/pain/aggression/inhibition; play invitations/pauses/role reversals/self-handicapping/escalation; human pointing/gesture/attention/social referencing/cues; multimodal integration; development/aging/socialization/health/sensory loss/morphology/history/environment; other-animal interactions. Explicitly assess language, meaning, intentionality and syntax without treating learned cue response as human linguistic capacity.
7. For every signal cluster describe observable features, plausible meanings, required context, alternatives/confounds, evidence strength, proportionate human responses and referral thresholds. Include misinterpretation tables. Never infer friendliness from a wag alone or suppress growling. State when evidence is missing rather than filling gaps with folklore.
8. Finish with a training chapter explaining conditioning, reinforcement, shaping, capturing, prompting/fading, generalization/discrimination, habituation, desensitization/counterconditioning, timing, motivation, stress and environment. Generate the full competency inventory and individual plans using curriculum-contract.md. Label designer-selected criteria as adjustable examples, not experimentally proven thresholds. Use reward-based methods, choice and welfare safeguards; avoid flooding, coercion and suppression of warnings. Refer suspected pain, aggression, severe fear and separation distress for veterinary assessment and qualified behavior support. Do not give diagnostic or medication prescriptions or promise fixed timelines.
9. Attach sequential Chicago notes to factual claims. Use verified PDF pages only; use section locators for HTML. Generate notes, alphabetized bibliography and source matrix from one source registry, with exact correspondence and stable links. Distinguish cited originals from secondary reports; never imply an unread cited original was examined.
10. Generate unique AI banners for every substantive section/subsection and unique additional illustrations approximately every 500 body words, excluding banners from that count. Apply visual-contract.md, maintain the inventory, and use vector diagrams for exact science. Never manufacture diagrams as generated empirical data.
11. Export PDF, curriculum, templates, protocol, search log, evidence matrix, source registry, image inventory and QA report. Run scripts/validate_run.py RUN_DIR and inspect every rendered PDF page. Correct defects and rerun only affected checks. Report unfinished checks candidly; a scaffold or partial monograph is not a complete execution.
12. Persist user-facing deliverables and save skill changes by committing only ski/ and pushing the current Skills branch. Never commit unrelated work. Do not claim installation before push succeeds.

## Incremental operation
Research: perform the full workflow. Update: search from the last verified cutoff, plus targeted checks for corrections/retractions; reevaluate affected claims and plans. Dog: reuse general evidence, assess profile gaps and tailor plans with clinical referral boundaries. Render: reuse verified content and source records; recheck changed links/formatting/images without claiming a new literature search. Invalidate downstream artifacts whenever their source hash changes. Preserve run-level access and limitations logs.

## Mode-specific acceptance
For research/update, require the full monograph and companion deliverables. For dog, complete a case plan and its evidence, profile gaps, session template and case QA; do not claim a full monograph was produced unless separately requested and verified. For render, require preexisting verified manuscript, source/claim registries and image assets. If missing, report required inputs and preserve the incomplete run; do not silently change modes. Apply only relevant execution gates to case/render outputs. Skill frontmatter, script testing and Git saving are development gates, required when changing the skill rather than on every invocation. Structural validation never establishes research, citation, image or visual correctness.

## Completion
Use acceptance.md as a blocking checklist. Deliver a concise status, accessible PDF and companion outputs, actual search coverage, material gaps, and commands/examples `/ski update`, `/ski dog recall`, `/ski render`. If any requirement is unavailable, preserve progress and label the execution incomplete rather than lowering the contract silently.
